# 安装与运行

## 环境

- Windows 11
- Python 3.10 或更高版本；本次验证使用 Python 3.12.14
- 建议 16 GB RAM，至少 20 GB 可用磁盘空间
- 真实文献检索需要外网；离线演示不需要外网

## 首次安装

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
copy .env.example .env
python scripts/init_database.py
```

编辑 `.env`：

- 设置一个本地 `API_KEY`，用于 REST API 的 `x-api-key` 请求头。
- `OPENAI_API_KEY` 可留空；留空时系统进入 mock 降级模式。
- 如需更高检索额度，可配置 `SEMANTIC_SCHOLAR_API_KEY`。

如果 Python 3.12 安装 `torch` 时找不到匹配轮子，可先安装 CPU 版：

```powershell
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 启动

```powershell
# Web 界面（推荐）
python main.py --mode web

# REST API
python main.py --mode api

# 命令行
python main.py --mode cli --query "perovskite solar cell stability" --trl --hypotheses
```

启动后访问：

- Web：`http://localhost:8501`
- API 文档：`http://localhost:8000/docs`

也可以直接双击 `start_web.bat`。需要关闭终端后继续运行时，使用 `start_web_bg.bat`；停止服务使用 `stop_web.bat`。

## 离线演示

1. 启动 Web。
2. 点击右上角「演示」。
3. 或直接打开 `http://localhost:8501/#/workbench/demo`。

内置数据位于 `src/web/static/demo/`，包含 12 篇文献、知识图谱、TRL、假设和 Markdown 报告。

## 测试

```powershell
venv\Scripts\python.exe -m pytest tests -q -p no:cacheprovider
```

预期结果：`29 passed`。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 8501 端口被占用 | 关闭旧进程，或修改 `.env` 的 `WEB_PORT` |
| 真实检索返回 0 篇 | 检查外网、代理和英文关键词；可先用离线演示 |
| Semantic Scholar 被限流 | 配置 `SEMANTIC_SCHOLAR_API_KEY`，或等待限流窗口结束 |
| 中文问题命中率低 | 使用英文关键词，或在界面保留中文主题让系统自动抽取与翻译 |
| 创新假设为空或偏模板 | 配置 `OPENAI_API_KEY`；未配置时属于预期的 mock 降级行为 |

## 提交前检查

- 不要打包 `.env`、`venv/`、`logs/`、`data/`、`cache/` 和 `reports/`。
- 确认 GitHub 仓库地址可匿名打开。
- 如果 API Key 曾出现在公开文档或截图中，先轮换再提交。
