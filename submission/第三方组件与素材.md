# 第三方组件与素材说明

## 项目许可证

本项目代码采用 Apache License 2.0，许可证全文见仓库根目录 `LICENSE`。

## 主要第三方组件

| 组件 | 用途 |
| --- | --- |
| FastAPI、Uvicorn | REST API 与 Web 服务 |
| Pydantic、pydantic-settings | 配置与数据校验 |
| NetworkX、python-louvain | 知识图谱、社区检测 |
| scikit-learn | 文本特征与相似度分析 |
| aiohttp、certifi | 异步学术数据源请求与证书 |
| SQLite | 本地任务、缓存与审计数据 |
| cryptography、bcrypt、PyJWT | 加密、密码哈希与令牌 |
| PyTorch（可选） | 设备检测与本地模型支持 |

第三方组件按其发行包附带的许可证使用；正式提交前请以竞赛规则和组件发行方的许可证为准。

## 外部数据源

arXiv、PubMed、Semantic Scholar 的检索结果受各自 API 条款和限流策略约束。系统只保存检索结果用于当前任务与本地缓存；对外发布数据前应再次核对数据源的使用条款。
