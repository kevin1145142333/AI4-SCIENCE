# AI4 Science 作品提交说明

## 作品定位

AI4 Science 是面向科研人员的多智能体研究辅助工作台。用户提交一个研究问题后，系统完成多源文献检索、去重与质量分析、知识图谱构建、TRL 技术成熟度评估、创新假设与反事实推演，并输出可阅读、可下载的研究报告。

项目对应「科研创新」赛道，重点解决文献调研耗时、研究脉络难梳理、技术成熟度缺少量化依据、创新假设依赖个人经验四个问题。

## 最快演示路径

1. 启动 Web：在项目根目录运行 `start_web.bat`，或执行 `python main.py --mode web`。
2. 打开 `http://localhost:8501`。
3. 现场提交任务：在「指挥舱」输入研究问题，选择分析深度，点击「启动研究任务」。
4. 无网络时：点击右上角「演示」，或直接打开 `http://localhost:8501/#/workbench/demo`。

## 需要如实说明的边界

- arXiv、PubMed、Semantic Scholar 以英文检索为主；中文长句会先抽取主题再翻译。
- 未配置 LLM 时，创新假设会走模板或 mock 降级分支，内容可用但不等于领域专家判断。
- TRL 结果是系统基于检索证据的评估，不替代正式技术评审或专家结论。
- 真实检索依赖外网与数据源限流；现场演示建议同时准备离线数据。
- Dockerfile 与 compose 文件随仓库提供，但本次验收以 Windows 本地 Python 部署为准，容器路径未作为已验证项。
